This project is for training purposes, which includes multiple codes for different applications 
 1- review reports: 
this code go through up to 700 row of data, takes certain data, perform an analysis, and finally create a report based on static data from the sheet and the analysis results, in addition to creating graphs which represents these results.
 2- incident reports:
daily incidents must be documneted and reported, the code makes it easy to automatically generate the report by a click. with the same previous principles.
 3- Hr management script
Allow Manageer to manipulaate leave days of employees using a start and end date of the vacation, check validity and confirm it.
